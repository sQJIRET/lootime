# Loontime Donate: сайт доната + плагин для Paper 1.21

Две части:
- `site/` — сайт (Node.js 22+): витрина, админка, оплата через Platega, API для плагина.
- `plugin/` — плагин Paper 1.21: каждые 5 с спрашивает сайт о новых заказах и выполняет команды выдачи.

Как это работает: игрок платит на сайте → Platega шлёт callback на сайт → сайт перепроверяет платёж у Platega и ставит команды в очередь → плагин забирает очередь и выполняет команды от имени консоли. Плагину не нужны открытые порты: он только отправляет запросы на сайт.

## 1. Сайт

Сайту нужен Node.js 22.13+ и публичный адрес с **HTTPS** (Platega принимает callback только на HTTPS с валидным сертификатом). Хостинг самого Minecraft-сервера для этого обычно не подходит. Нужен VPS или хостинг с Node.js.

```bash
cd site
npm install
cp .env.example .env     # заполните значения
npm start
```

В `.env` обязательно задайте `PUBLIC_URL`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `PLUGIN_KEY`, `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`.

В личном кабинете Platega: **Настройки → Callback URLs** → `https://ВАШ_САЙТ/api/platega/callback`.

Пробный запуск без оплаты: `DEV_MODE=1` и пустые ключи Platega. Кнопка «Оплатить» сразу засчитывает заказ. В бою держите `DEV_MODE=0`.

Админка: `https://ВАШ_САЙТ/admin`. Там товары, заказы (ручная выдача, повтор выдачи) и настройки сайта (название, IP, ссылки, правила).

### Домен и HTTPS (loontime.duckdns.org)
Сайт сам получает бесплатный сертификат Let's Encrypt и продлевает его. Нужно:
1. В DuckDNS направить `loontime.duckdns.org` на публичный IP сервера, где запущен сайт.
2. Открыть и освободить порты 80 и 443 (на Linux без root: `sudo setcap 'cap_net_bind_service=+ep' $(which node)`).
3. В `.env`: `PUBLIC_URL=https://loontime.duckdns.org`, `HTTPS_DOMAIN=loontime.duckdns.org`, `TRUST_PROXY=0`.
4. `npm install` (появилась зависимость `acme-client`) и `npm start`. Для пробы можно `ACME_STAGING=1`, потом вернуть `0` и удалить папку `data/certs`.

Если у хостинга нельзя занять 80/443, используйте `Caddyfile` из архива или Cloudflare перед сайтом.

### Хостинг с одним портом (например, coding.netrix.pw:19013)
Сайт сам принимает на одном порту и `http://`, и `https://` (самоподписанный сертификат, нужен `openssl`). По https браузер покажет предупреждение «не защищено» — нажмите «Дополнительно → продолжить». Доверенный сертификат без порта 80/443 получить нельзя: для этого поставьте Cloudflare или Caddy перед сайтом. Если Platega не настроена, сайт всё равно запускается (оплата отключена). `DEV_MODE=1` — оплата имитируется, товары выдаются бесплатно.

### Корзина и оплата
Игрок собирает в корзину несколько товаров, вводит ник, email (необязательно) и промокод, выбирает способ оплаты и платит одним платежом. Промокоды задаются в `.env`: `PROMO_CODES=LOON10:10,VIP5:5`. Рядом с кнопкой «Оплатить» и в подвале стоят ссылки на политику конфиденциальности и пользовательское соглашение (telegra.ph). Это шаблоны: подставьте данные проекта и актуальную дату.

### Команды выдачи
В товаре пишете команды по одной в строке, без `/`. Подстановки: `{player}` — ник, `{qty}` — количество. Примеры:
```
lp user {player} parent add vip
eco give {player} {qty}
crates key give {player} common {qty}
unban {player}
```
Опция «только когда игрок онлайн» откладывает выдачу, пока игрок не зайдёт.

## 2. Плагин

Используйте плагин `LoontimeDonate` (v2) в режиме `mode: "remote"`, он забирает заказы с этого сайта. Настройка: в `config.yml` плагина
`remote.api-url` = адрес сайта, `remote.api-key` = `PLUGIN_KEY` из `.env`. Подробности в README плагина.

Старая схема (отдельный плагин-опросчик из папки `plugin/`) описана ниже.

Сборка: `cd plugin && mvn package` → `plugin/target/LoontimeDonate-1.0.0.jar`. Или выложите проект на GitHub: Actions соберёт jar сам (`.github/workflows/build-plugin.yml`).

Положите jar в `plugins/`, запустите сервер, откройте `plugins/LoontimeDonate/config.yml`:
```yaml
api-url: "https://ВАШ_САЙТ"
api-key: "тот же PLUGIN_KEY из .env"
```
Затем `/ltd reload`. `/ltd status` покажет время последнего опроса и ошибки.

## Безопасность
- Callback Platega проверяется по заголовкам и дополнительно перепроверяется запросом к Platega (статус и сумма).
- Недоплата уходит в статус «на проверке» и не выдаётся.
- Команды хранятся только на сервере сайта; витрина их не показывает.
- Если подтверждение выдачи не дошло до сайта, команда может выполниться повторно. Это защита от потери выдачи.

## Правила Mojang
Продавать можно привилегии и косметику, но не игровое преимущество за деньги (EULA). Иначе сервер могут заблокировать.

## Структура API
Все запросы `/api/*` идут через папку `src/api`: `index.js` (общий роутер), `shop.js` (витрина, промокод, заказ), `platega-callback.js`, `plugin.js` (для плагина), `admin.js`, `delivery.js` (выдача после оплаты). Адреса остались прежними.


## Токены

Товар «Токены» продаётся по курсу 1 ₽ = 1000 токенов, покупать можно любое количество от 1000 (поле «Цена за N шт.» = 1000). В команде выдачи `{qty}` — это уже число токенов (`TOKENS_COMMAND=points give {player} {qty}`).
